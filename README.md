# calculator

A deliberately boring calculator. The interesting system is [Save Point](https://github.com/thierrypdamiba/save-point).

```python
calculate(4, "+", 3)   # 7
calculate(4, "-", 3)   # 1
calculate(4, "*", 3)   # ValueError: Unsupported operator
```

Behavior is specified in `calculator.feature` before it is implemented in `calculator.py`.
